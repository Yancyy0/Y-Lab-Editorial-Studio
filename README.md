# Yancy's Lab · Editorial Studio

## Local development

```bash
npm ci
npm run dev
```

## Cloudflare Pages

- Framework preset: `Next.js (Static HTML Export)`
- Build command: `npm run build`
- Build output directory: `out`
- Node.js version: `22.13.0` or newer

The repository contains no required environment variables. Cloudflare Pages can build it directly after the GitHub repository is connected.
